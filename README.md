# 真车主营销后台原型

本原型基于 `tc-flight-marketing-flyactapi14mng` 中现有完单返现、`driverTaskCenter`、`carOwnersExpansionRate` 和 `carOwnersLottery` 后台页面结构复现，通过左侧菜单提供四个后台页面：

- 完单返现
- 任务中心后台
- 会员权益膨胀
- 真车主抽奖

## 完单返现页面

- 是否聚合到任务中心：必选，历史活动默认“否”。
- 选择“是”时，展示任务中心现有全部前端样式字段。
- 选择“否”时，隐藏任务中心样式字段，保留原完单返现活动配置和展示逻辑。
- 任务标题在聚合时必填；展示顺序必须为 1～99 的正整数。
- 任务标签选择“新手任务”时，展示新手任务专属 icon、标题和副标题。
- 聚合到任务中心后，可选择是否开启认证通过倒计时；开启时需配置 1～20 天。
- 聚合到任务中心后，可选填奖励中心入口文案。

## 任务中心后台页面

- 沿用现有任务中心的任务基础配置、投放限制、任务配置、奖励配置和前端样式配置。
- 选择完单任务时，仅允许选择普通奖励，现金奖励不可选。
- 选择发布行程或添加常用线路任务时，仅允许选择现金奖励，普通奖励不可选。
- 完单任务支持选填消息触达方式，使用多选控件，本次仅提供马达平台。
- 历史配置的消息触达方式默认不勾选。
- 选择发布行程或添加常用线路任务时，不展示消息触达模块。
- 前端样式配置新增奖励中心入口文案，非必填。

## 会员权益膨胀页面

- 保留现有基础信息、权益获取方式、参与限制、权益有效期和权益发放通知配置。
- 活动配置模块新增常规膨胀比例，必填，支持 1～50 的正整数。
- 新增前端样式模块，支持选填奖励中心入口文案。

## 真车主抽奖页面

- 保留现有基础信息、活动限制、抽奖次数、用户分组、前端样式、外显奖品和消息触达配置。
- 在前端样式配置模块新增奖励中心入口文案，文本输入框，非必填。
- 在前端样式配置模块新增最高奖励价值，金额输入框，非必填；填写时必须大于 0，最多保留两位小数。

直接打开 `index.html` 或通过本地静态服务访问即可预览，并可通过左侧菜单切换页面。
